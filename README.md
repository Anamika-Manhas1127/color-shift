-> Color Shift 🎨

A simple, interactive web project that changes the background to beautiful pastel colors with every click.

-> Features

- Changes the background color with a button click.
- Generates soft pastel colors.
- Displays the current color's HEX code.
- Clean, minimal, and user-friendly design.
- Responsive layout for a pleasant browsing experience.

-> Technologies Used

- HTML5
- CSS3
- JavaScript

-> How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Anamika-Manhas1127/color-shift.git
   ```

2. Open the project folder in VS Code.
3. Open `workshop.html` in your browser to use the website.
